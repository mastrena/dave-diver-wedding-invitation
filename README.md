# BLUE HOLE WEDDING｜深海冒险婚礼请柬

一份专为手机设计的互动婚礼请柬 Demo。宾客会像接受游戏任务一样打开邀请函，经历下潜、领取委托、声呐探索、捕捉祝福鱼、查看婚礼日程与地图，最后完成宾客登记。

无需安装框架或运行构建命令，项目只使用 HTML、CSS 和 JavaScript。完全没有编程经验，也可以按照教程替换成自己的内容。

> 🌊 [立即体验在线 Demo](https://mastrena.github.io/dave-diver-wedding-invitation/)

## 页面包含什么

- 手机端沉浸式深海首页
- 点击开始任务和背景音乐控制
- 长按接受婚礼委托
- 滚动深度、氧气与鱼群数量 HUD
- 声呐扫描和随机祝福鱼彩蛋
- 角色来电轮播
- 婚礼日程、倒计时、地图入口
- 宾客姓名、人数、住宿和留言登记演示
- 微信及社交平台分享标题、简介和图片

## 先说清楚：公开 Demo 不会收集信息

仓库里的宾客登记是安全的演示模式。访客填写的信息只保存在访客自己的浏览器中，不会发送到服务器，也不会进入新人的正式宾客名单。

如需接入真实登记后台，请阅读 [新手定制教程](./GUIDE.zh-CN.md#九宾客登记如何变成真的)。

## 三分钟开始

1. 点击 GitHub 页面右上方绿色 **Code** 按钮。
2. 选择 **Download ZIP**，下载并解压。
3. 用记事本、VS Code 或其他文本编辑器打开 `index.html`。
4. 搜索“新郎”“新娘”“2030”“示例市”，替换成自己的信息。
5. 打开 `app.js`，把第一行的婚礼日期改成自己的日期。
6. 双击 `index.html` 预览。

完整的逐步说明、图片替换尺寸、音乐、地图、微信分享和部署方法，请看：

> 📘 [完全零基础的新手定制教程](./GUIDE.zh-CN.md)

## 发布到 GitHub Pages

上传代码后，进入仓库：

1. 点击 **Settings**。
2. 左侧点击 **Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 分支选择 `main`，目录选择 `/ (root)`。
5. 点击 **Save**。

稍等几分钟，网站通常会发布到：

```text
https://你的用户名.github.io/仓库名/
```
