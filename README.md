# BLUE HOLE WEDDING｜深海冒险婚礼请柬

一份专为手机设计的互动婚礼请柬 Demo。宾客会像接受游戏任务一样打开邀请函，经历下潜、领取委托、声呐探索、捕捉祝福鱼、查看婚礼日程与地图，最后完成宾客登记。

无需安装框架或运行构建命令，项目只使用 HTML、CSS 和 JavaScript。完全没有编程经验，也可以按照教程替换成自己的内容。

> 🌊 [立即体验在线 Demo](https://blue-hole-wedding-invitation-demo.pages.dev/)

## 页面包含什么

- 手机端沉浸式深海首页
- 点击开始任务和背景音乐控制
- 长按接受婚礼委托
- 滚动深度、氧气与鱼群数量 HUD
- 声呐扫描和随机祝福鱼彩蛋
- 角色来电轮播
- 婚礼日程、倒计时、地图入口
- 宾客姓名、人数、住宿和留言登记演示
- 微信及社交平台分享标题、简介和图片

## 先说清楚：公开 Demo 不会收集信息

仓库里的宾客登记是安全的演示模式。访客填写的信息只保存在访客自己的浏览器中，不会发送到服务器，也不会进入新人的正式宾客名单。

如需接入真实登记后台，请阅读 [新手定制教程](./GUIDE.zh-CN.md#九宾客登记如何变成真的)，或直接按 [零基础宾客管理后台教程](./RSVP_BACKEND.zh-CN.md) 操作。教程分别提供 WPS 文档、腾讯文档、飞书和问卷星示例；创建表单后，只需在 `app.js` 粘贴一行公开填写链接。

## 三分钟开始

1. 点击 GitHub 页面右上方绿色 **Code** 按钮。
2. 选择 **Download ZIP**，下载并解压。
3. 用记事本、VS Code 或其他文本编辑器打开 `index.html`。
4. 搜索“新郎”“新娘”“2030”“示例市”，替换成自己的信息。
5. 打开 `app.js`，把第一行的婚礼日期改成自己的日期。
6. 双击 `index.html` 预览。

完整的逐步说明、图片替换尺寸、音乐、地图、微信分享和部署方法，请看：

> 📘 [完全零基础的新手定制教程](./GUIDE.zh-CN.md)

## 完全不会代码？把这段话直接交给 AI

适合希望由 AI 完成绝大部分定制、只愿意提供新人信息和照片的用户。复制下方整段提示词，连同本项目文件夹一起交给你常用的 AI 编程助手即可。

```text
我是完全不会编程的新手。请基于我提供的「婚礼请柬项目文件夹」为我完成定制，不要只告诉我怎么做；请直接修改文件，并在完成后告诉我哪些文件已改、如何预览和如何上线。

我的婚礼信息如下：
- 新人姓名（中文 / 英文）：[填写]
- 婚礼日期与时间：[填写]
- 婚礼地点与地图链接：[填写]
- 当天流程：[填写]
- 想对宾客说的话：[填写]
- 照片文件：[填写或稍后补充]
- 是否需要宾客登记：[需要 / 不需要]
- 背景音乐：[保留默认 / 我提供文件]
- 网站域名（如有）：[填写]

请按以下要求执行：
1. 保留项目的互动感、页面结构和整体视觉气质，但所有文字都替换成我的真实信息；没有提供的信息先使用清晰的占位内容，并在最后单独列出待我补充的项目。
2. 优先保证手机体验：在 375px、390px、430px 宽度下检查首页、信息卡、时间轴、地图、登记表和底部按钮，避免文字溢出、按钮遮挡或横向滚动。
3. 宾客登记在未接入后端前，必须只保存在访客自己的浏览器中；不要把姓名、电话、留言或任何表单信息发送到第三方服务。若我要求真实收集，再先向我说明数据存在哪里、我如何查看和导出。
4. 生成适合微信转发的标题、简介和分享图片；不要在公开 Demo、截图或仓库中留下我的真实姓名、地址、电话、精确地图坐标或婚礼日期。
5. 不要未经我确认就部署、购买服务、绑定域名、创建账号、上传私人照片或提交真实宾客数据。需要这些操作时，先列出最少的操作步骤让我确认。
6. 如果这个项目要公开发布，请将游戏角色、Logo、字体、音乐和其他第三方素材替换为原创或已获授权的素材；“非商业”“侵删”或版权声明不能代替授权。
7. 上线后请给我一份“亲友分享包”：最终 HTTPS 网页地址、适合长辈和朋友的两版微信文案、二维码制作方法、手机测试清单。不要把本地文件地址或 GitHub 仓库地址当成邀请函链接。
8. 完成后请给我：已修改文件清单、手机端检查结果、预览方式、上线方式，以及我还需要补充的内容。
```

## 发布成网址：两种方式选一种

### 方式一：让 AI 工具帮你发布（不懂技术首选）

无需额外注册 GitHub，也不需要理解 Git；仍需登录你选择的 AI 工具，并以其当前发布权限和额度为准。把项目文件夹交给支持网页发布的 AI 工具，说一句「发布上线，生成一个可以分享的网址」，通常就能拿到 HTTPS 链接。详细步骤、可直接复制的提示词和排错清单见：

> 🚀 [用 AI 工具一句话生成分享网址](./AI_PUBLISH_GUIDE.zh-CN.md)

### 方式二：发布到 GitHub Pages（想自己掌控）

如果你想把自己定制后的版本发布到 GitHub Pages，进入仓库：

1. 点击 **Settings**。
2. 左侧点击 **Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 分支选择 `main`，目录选择 `/ (root)`，然后保存。

稍等几分钟，网站通常会发布到：

```text
https://你的用户名.github.io/仓库名/
```

## 做好以后，怎么发给亲朋好友

请把**部署后的 HTTPS 网页地址**发给宾客，不要发送电脑上的 `index.html`、`localhost` 地址或 GitHub 仓库地址。

推荐顺序：

1. 先请 2～3 位亲友分别用苹果和安卓手机试开。
2. 检查首页、音乐、地图、底部导航和宾客登记。
3. 再通过微信私聊或群聊发送网页地址，并配一小段邀请文字。
4. 另外制作一张带二维码的邀请海报，作为朋友圈、纸质请柬和现场指示牌的备用入口。

完整步骤、微信分享卡片说明、二维码检查方法和可直接复制的邀请文案见：

> 💌 [做好邀请函后，如何分享给亲朋好友](./SHARE.zh-CN.md)

网址交给 AI 工具生成的，发布后同样按上面四步检查；AI 生成页面的常见坑见 [AI 发布教程第七节](./AI_PUBLISH_GUIDE.zh-CN.md#七排错速查)。
